# Instruções de simulação

Ferramenta: Typhoon HIL Control Center / TyphoonSim.

Arquivos incluídos:

- `instrumento-estatico-generico.tse` — modelo do instrumento
- `instrumento-estatico-generico.cus` — painel SCADA

## Passos

1. Abra o arquivo `.tse` no Schematic Editor.
2. Execute a simulação com **Run TyphoonSim**.
3. Abra o painel `.cus` para acompanhar os indicadores virtuais.
