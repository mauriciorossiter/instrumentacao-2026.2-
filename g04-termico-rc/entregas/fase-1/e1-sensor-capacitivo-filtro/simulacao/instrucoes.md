# Instruções desta entrega

Ferramenta: Typhoon HIL Control Center / TyphoonSim.

## Arquivos

- `relatorio/relatorio.pdf` — relatório da entrega
- `apresentacao/apresentacao.pptx` — slides de apoio
- `simulacao/sensor-hs1101lf-filtro.tse` — modelo do sensor com filtro

## Passos

1. Abra o arquivo `.tse` no Schematic Editor.
2. Execute a simulação com **Run TyphoonSim**.
3. Verifique a resposta do sensor capacitivo HS1101LF com o filtro de condicionamento.
